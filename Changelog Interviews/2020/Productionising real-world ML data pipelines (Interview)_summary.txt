• Kedro is a Python library for data pipelines developed by QuantumBlack, an advanced analytics company acquired by McKinsey.
• Kedro is the first open-source product from QuantumBlack, released in response to client demand for a reproducible and deployable data science tool.
• The library is designed to apply software engineering best practices to data science and data engineering code, making it easier to put code into production.
• Kedro is built on top of Cookie Cutter Data Science and aims to standardize workflow consistency and data abstraction in data pipelines.
• The open-sourcing of Kedro has led to a community-driven development and adoption of the library, with users creating reusable analytics libraries and contributing to the project's growth.

• Data catalog: a series of extendable data connectors for loading and saving data
• Nodes: pure Python or PySpark functions that accept input and produce output
• Pipelines: a series of nodes that work together to process data

• The team's name, Kedro, was changed after realizing it might infringe on trademarks, and it now means "the center" in Greek, representing the tool's central role in data pipelines.
• The team spent significant time on documentation to support users, as they knew users would come to the tool with questions and need to troubleshoot quickly.
• The open-sourcing of Kedro led to unexpected challenges, including a large influx of GitHub issues and Stack Overflow questions, which the team was not prepared for.
• The team implemented a rotating "Wizard" role to manage user queries and developed new roles, such as developer advocates, to scale support for open-source users.
• The naming process for Kedro involved extensive stakeholder management, social media checks, reference meaning checks, and trademark searches across multiple jurisdictions.
• The team considered alternative names, including Braze, Knittic, and Spindle, which were ultimately rejected due to trademark issues or other concerns.
