• Foundation is a responsive framework developed by Zurb
• Foundation was built from the Zerb style guide, a set of resets and common styles for front-end code
• The framework was adapted from a fixed-width design to a responsive design for desktops, tablets, and phones
• Foundation's main distinction from Twitter Bootstrap is its responsiveness and flexibility
• Foundation is designed to be a more extensible and customizable framework than Bootstrap
• Foundation incorporates aspects of HTML5 Boilerplate and includes a grid system, common elements, and a construct for quickly doing layouts
• The framework has been ported to various server-side frameworks, including Rails, WordPress, and .NET MVC, but Zurb's primary focus is on Ruby on Rails.
• Foundation is designed to be accessible to everyone, avoiding opinionated tools like Sass and Haml
• The goal is to make it easy for anyone to contribute to and use Foundation, without requiring knowledge of specific tools
• The decision to avoid Sass and Haml is to prevent a "holy war" and make Foundation more inclusive
• As a company, Zurb (the developers of Foundation) don't standardize on specific tools, but focus on vanilla CSS
• Zurb often hands off front-end assets (e.g. style guides or templates) to external teams, making vanilla CSS a necessity for compatibility
• The Foundation project on GitHub has gained a large following (over 1,600 watchers) in a short time (about a month)
