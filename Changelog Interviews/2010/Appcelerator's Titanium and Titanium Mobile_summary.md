• Appcelerator developed Titanium Desktop to allow web developers to create native desktop applications.

• Titanium Desktop is an open-source, true cross-platform desktop SDK for writing native apps using web technologies.
• The project tackled the problem of complexity in traditional cross-platform desktop APIs and the need for web developers to send content at a native level.
• The team used WebKit for Windows, OS X, and Linux, and separate versions for iPhone and Android due to their respective programming languages.
• The platform provides a common API across Android and iPhone, as well as specific APIs for each platform.
