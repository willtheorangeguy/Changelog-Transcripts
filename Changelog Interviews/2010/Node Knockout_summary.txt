• Background and inspiration for Node Knockout, which was inspired by the Rails Rumble competition
• Node Knockout is a 48-hour programming contest where teams build a project from scratch using Node.js
• Teams start with no digital assets and can only use open-source libraries
• The contest is similar to Rails Rumble and Django Dash, but with a focus on Node.js
• 98 teams produced a reasonable product, and a handful of businesses have been created from previous contests
• Judges include VCs who can provide funding for promising projects
• Some notable projects include Swarm Nation, Watchmaker, and MapReduce
• Contestants used a variety of creative approaches, including a multiplayer game built on a webpage and a multiplayer tower defense/offense game
• Real-time communication apps and one-pager web apps submitted
